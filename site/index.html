Minimal by design

Private by construction

Your inbox is not a data source.

  • No telemetry.There is no opt-in because nothing is collected.
  • Remote images blocked.Tracking pixels and network images stay off until you choose otherwise.
  • Secrets in the keyring.Passwords and tokens never go into SQLite, logs or MCP responses.
  • HTML isolated.JavaScript is off; mail CSS and links pass explicit safety policies.
